# ภาพพิกเซล 2D ของออฟฟิศ

ออฟฟิศมี 2 แบบภาพ: **พิกเซล 2D** (ค่าเริ่มต้น) และ **3D** พนักงานทำงาน เดิน นั่ง และตอบสนองเหมือนกันทั้งสองแบบ ต่างกันแค่วิธีวาด

## ใช้งาน
- สลับแบบภาพ: ปุ่มเฟือง (Settings) → View → Pixel 2D หรือ 3D หน้าจะโหลดใหม่เอง ค่าเก็บในเบราว์เซอร์ (`agent-office:view`)
- บังคับชั่วคราวด้วยลิงก์: ต่อท้าย `?view=pixel` หรือ `?view=3d`
- เลื่อนฉาก: ลากเมาส์ ซูม: ล้อเมาส์ (1 ถึง 4 เท่า) กดเดิน WASD แล้วกล้องกลับมาตามตัวผู้เล่น
- ธีมมืดของแอป = กลางคืน (ป้ายไฟ โคม ไฟรถสว่าง) ธีมสว่าง = กลางวัน
- ถ้าภาพพิกเซลวาดไม่ได้ หน้านั้นจะสลับเป็น 3D เองและเขียนเตือนใน console

## ในฉากมีอะไร
- ในออฟฟิศ: ของ 22 ชนิดตาม `src/shared/catalog.ts` ห้องแต่ละฝ่าย ป้ายชื่อห้อง และพนักงานทุกคนแต่งตาม `src/client/domain/looks.json`
- นอกออฟฟิศ: ตึกของบริษัทพร้อมป้ายไฟชื่อบริษัท ตึกแถวเพื่อนบ้าน 8 ร้าน ทางเท้า รถเข็น คนเดิน ถนน 2 เลน รถ 4 ชนิด และทางม้าลายตรงประตู
- ถนนเป็นของตกแต่ง คนเดินถนนและรถไม่เข้าออฟฟิศ และไม่เกี่ยวกับงานของพนักงาน สีและร้านต่างกันตามชื่อบริษัท

## โค้ดอยู่ที่ไหน
ทั้งหมดอยู่ใน `src/client/infrastructure/pixel/`

| ไฟล์ | หน้าที่ |
|---|---|
| `types.ts` | สัญญากลาง: ขนาดช่อง 16 พิกเซล, `PixelBuffer` (ภาพที่วาดด้วยโค้ด), ชนิดข้อมูลที่ทุกไฟล์ใช้ร่วมกัน |
| `palette.ts` | ชุดสีเดียวของทั้งฉาก และธีมสีของถนน 4 แบบ |
| `people.ts` | ตัวคน: 10 ท่า × 4 ทิศ จากข้อมูลหน้าตา |
| `furniture.ts` | ของในออฟฟิศ พื้น ผนัง |
| `city.ts` | ถนน ตึก ร้าน รถ คนเดิน |
| `projection.ts` | แปลงจุดบนจอเป็นจุดบนพื้น ลำดับวาด การคลิกโดนใครหรือโดนของชิ้นไหน |
| `pixelView.ts` | วงวาดหลัก กล้อง ป้ายชื่อ แสงกลางคืน ฝน |
| `dev/` | สคริปต์ทำภาพรวม (contact sheet) สำหรับดูงานภาพ ไม่ถูกรวมในแอป |

สมองของออฟฟิศ (ใครไปไหน นั่งตรงไหน) ยังอยู่ที่ `three/world.ts` ตัวเดียว โหมดพิกเซลไม่สร้าง WebGL และไม่โหลดโมเดล 3D

## แก้ภาพ
1. แก้ฟังก์ชันวาดใน `people.ts` `furniture.ts` หรือ `city.ts` ใช้สีจาก `palette.ts`
2. ทำภาพรวมดู: `node --import tsx src/client/infrastructure/pixel/dev/sheetPeople.ts <โฟลเดอร์ปลายทาง>` (มี `sheetOffice.ts` และ `sheetCity.ts` เช่นกัน)
3. รันเทสต์: `node --import tsx --test "src/client/infrastructure/pixel/*.test.ts"`
4. build: `npm run build` แล้วเปิดออฟฟิศ

ตัวหนังสือไทยบนป้ายวาดที่ความละเอียดจอจริง ไม่ย่อเป็นพิกเซล เพราะสระและวรรณยุกต์ขนาดเล็กอ่านไม่ออก ป้ายแนวตั้งไม่ใช้คำที่ขึ้นต้นด้วยสระหน้า (เ แ โ ไ ใ) เพราะสระจะหลุดไปอยู่บรรทัดเดียว

## ตรวจคุณภาพ
- ความลื่น: เปิดหน้าออฟฟิศแล้วดู `document.querySelector('.pixel-scene').dataset.frameMs` (เวลาวาดเฉลี่ยต่อเฟรม 120 เฟรมล่าสุด หน่วยมิลลิวินาที)
- เกณฑ์รับงานและผลตรวจอยู่ใน `PLAN-pixel.md`

## ข้อจำกัดที่รู้
- เข้าร้านเพื่อนบ้านหรือขึ้นรถไม่ได้ ถนนเป็นฉากประกอบ
- เตียงและโซฟาใช้ท่านั่งเดียวกับเก้าอี้ (เหมือน 3D)
- หน้าตัวละครเป็นหน้าพิกเซลทั่วไป แยกคนด้วยทรงผม สีผม ผิว แว่น และชุด
- แอปมีภาษาอังกฤษและตุรกี ข้อความปุ่มสลับแบบภาพจึงมี 2 ภาษานี้

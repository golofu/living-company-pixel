# เปิดบริษัทตัวอย่าง (Windows)

ออฟฟิศที่พนักงานแต่ละคนเป็น Claude Code ทำงานได้จริง รับงาน ส่งงานต่อกันตามผังองค์กร และรายงานเมื่อเสร็จ มาพร้อมบริษัทตัวอย่าง "บ้านขนมดี" (ร้านขนมไทย 8 คน 3 ฝ่าย + ผู้จัดการ)

## ต้องมี

- Windows + Node.js 22 ขึ้นไป
- Claude Code ที่ login ด้วยบัญชี Claude แล้ว (ใช้โควตาแพ็กเกจ ไม่ต้องมี API key)

## ใช้งาน

1. ดับเบิลคลิก `เปิดบริษัท.cmd` (ครั้งแรกจะติดตั้งส่วนประกอบเอง 1-3 นาที)
2. เบราว์เซอร์เปิด http://127.0.0.1:4317 (ต่อท้าย `?view=pixel` หรือ `?view=3d` เพื่อเลือกมุมมอง)
3. คลิกตัวละคร (เช่น ผู้จัดการ "ดาวเรือง") แล้วพิมพ์งาน หรือกด 💬 มุมขวาล่าง
4. เลิกใช้ ดับเบิลคลิก `ปิดบริษัท.cmd` (ควรรอให้งานเสร็จก่อน)

ห้ามปิดหน้าต่าง PowerShell ที่ย่ออยู่ระหว่างใช้งาน นั่นคือเซิร์ฟเวอร์ของออฟฟิศ

ทุกงานที่สั่งใช้โควตา Claude ของคุณ ค่าเริ่มต้นจำกัดให้ทำงานพร้อมกันสูงสุด 3 คน และพนักงานแก้ไฟล์ได้เฉพาะในโฟลเดอร์งาน (`acceptEdits`)

## ใส่บริษัทของคุณเอง (เช่น ผังจาก Notion)

แก้ `rosters/sample.json` (UTF-8) แล้วเปิด `เปิดบริษัท.cmd` ซ้ำ ระบบจะแทนที่ทีมเมื่อไฟล์เปลี่ยน ควรทำตอนไม่มีงานค้าง

วิธีง่ายสุด: เปิดหน้าผังบริษัทใน Notion คัดลอกทั้งหน้า แล้วสั่ง Claude ว่า "แปลงผังนี้เป็นไฟล์ rosters/sample.json ตามรูปแบบเดิม หัวหน้าต้องมีชื่อลูกทีมในเครื่องหมายคำพูดและมอบงานด้วย delegate_task"

- รูปแบบไฟล์: `format: agent-office-team`, `version: 1`, `officeName`, `officeNotes`, `agents[]`
- แต่ละคนมี name, role, kind `agent`, provider `claude`, color, prompt, model `""`, permissionMode `acceptEdits`, allowedTools, team
- ชื่อห้ามซ้ำกัน prompt ของหัวหน้าต้องระบุชื่อลูกทีมในเครื่องหมายคำพูด และสั่งให้มอบงานด้วย `delegate_task`
- หน้าตาตัวละครแบบพิกเซลตั้งต่อชื่อได้ที่ `src/client/domain/looks.json` ชื่อที่ไม่มีในไฟล์จะได้หน้าตาเริ่มต้น

## ข้อมูล

- ข้อมูลออฟฟิศ: `offices/sample/data`
- งานที่พนักงานทำ: `offices/sample/งาน`
- log: `offices/sample/server.log`
